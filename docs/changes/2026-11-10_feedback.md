# Changes from the 10 November feedback

What was done for each item, the choices taken where the note left one, what the independent review found and fixed, and what is left. If this feedback is shared again with more notes, this page is updated rather than replaced.

Status key: **Done**, **Partly done**, **Not started**.

## Your decisions (10 November)

- U1: one screen, one list.
- F2: the homes show the dashboard; the Dashboard menu entry goes.
- F1: both: Futran staff departments, and a read-only list of every client's users.
- F3: keep the menu; the tabs inside the Law library page go.

## Client side

| Id | Item | Status | What was done |
|---|---|---|---|
| U1 | One place for AI systems | Done | One "AI systems" page (AI governance › AI systems) lists everything: register systems, tools and agents from the inventory and attestations, use cases, and the systems in the current audit. Each row shows a type (System, Tool or agent, Use case) and where it came from (Register, Inventory, Attestation, Discovery, Audit). Filters: type, source, department, stage, tier, in the current audit, not yet registered. One Add button (AI system, tool or agent, use case). The old AI inventory and Audit › AI systems addresses open this page with the matching filter. Every action from the old pages is still there (approve, mark not approved, review a use case, import from inventory). Nothing in your data was converted. |
| U2 | Audit stages as a timeline on Home | Done | Getting started and every client home show the nine stages of the current audit: done, current, upcoming, with dates where known. A stage opens its screen when the person's menu has it; otherwise a short summary of the stage opens. Futran QA (stage 6) always shows the summary. On phones the timeline is a vertical list. |
| U3 | Are integration connections in the AI or system inventory? | Done | Answered on the Integrations screen: a tool an integration finds is a suggestion until someone confirms it; once confirmed it becomes an inventory tool with source "Discovery" and appears on the AI systems page. Dismissed tools are not added. |

The full catalogue is one click away. |

## Choices taken

- The Chief Auditor had no home of their own (the Dashboard was it), so there is now "Chief Auditor home" with "Waiting for your approval" first.
- On each home the role's own lists come first and the dashboard section second.
- Upcoming stages on the timeline are still clickable; their screen shows its own "not yet" state.
- My work keeps its engagement cards, so engagements appear twice on that page.
- "In the current audit" on the AI systems page is shown only to people who pre-fill those systems.
- On Client users, the department filter matches by name across clients ("Finance" shows every client's Finance).

## What the independent review found and fixed

| Finding | Fix |
|---|---|
| A crafted "next" link on the mailbox step could send a signed-in person to another site. | Both the browser and server checks refuse it; covered by a browser test. |
| A system, tool or use case registered in a department you cannot see showed as "Not yet registered". | It now shows neither way. |
| The roles pivot CSV header could start a spreadsheet formula. | The header is made safe like the rows. |
| The initiation package's user CSV used older columns than the People screen. | Both use the People screen's columns. |

## Left

- A Futran user whose only role is Sales Manager or Pricing Approver now lands on the Sales screens (fixed with Release 2).
