# Futran Audit Platform demo: voice-over script

Narration for `e2e/demo-video-voice.mjs`. The on-screen captions are unchanged from `demo-video.mjs`; the narration is spoken over them.

Voice: Higgsfield preset voice Fraser, model seed_audio. Long pauses inside each clip are shortened to 0.42 s before timing. Each caption or title card is held for at least its clip length plus 0.6 s. Ids match `NARRATION` in the recorder.
